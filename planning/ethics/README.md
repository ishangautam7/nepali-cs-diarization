# Ethics documents: templates, not in use

These files were prepared for the planned D2-R conversation recordings (`planning/PLAN.md`, data table). Those recordings were never made: no participant was recruited, and no ethics approval was sought or obtained.

The bracketed placeholders, such as `[APPROVING BODY]`, are unfilled on purpose. Nothing in this folder describes the study reported in the paper, which uses only publicly released recordings (paper, Ethics and Reproducibility section).
