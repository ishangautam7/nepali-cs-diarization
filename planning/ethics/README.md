# Ethics documents for the planned conversation recordings

Consent forms, information sheets, a debrief, a recruitment notice, a data management plan and an ethics statement were drafted for the planned D2-R conversation recordings (`planning/PLAN.md`, data table). Those recordings were never made: no participant was recruited, and no ethics approval was sought or obtained. The drafts were never completed or used, and they are not part of this release.

None of this describes the study reported in the paper, which uses only publicly released recordings (paper, section "Ethics, Data Availability and Use of AI").
